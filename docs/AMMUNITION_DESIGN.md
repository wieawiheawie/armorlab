# Ammunition cell designs and material library

- `designs/material_library.json` — 13 materials (appearance, evidence, confidence, solver link kept separate; validated by `web/materials.js`). Reference-only copper/aluminium/tungsten-alloy/soft-iron entries exist for custom designs but no built-in uses them.
- `designs/builtin_designs.json` — 11 data-only cell templates (one per catalogue entry), generated by `npm run designs` (`scripts/gen_designs.js`). Each lists features as documented / approximate / not_drawn.
- `web/design.js` — model, edit ops, undo/redo, shared rasteriser, store (built-ins frozen; edits fork to a user copy; localStorage + JSON import/export).
- `web/design_ui.js` — Catalogue (thumbnails + inspection) and Cell editor (pencil, eraser, fill, replace, inspect, outline, mirror, symmetrize, zoom, mm ruler, legend).
- Solver, presets and Rust are UNCHANGED (`tests/fixtures/solver_config_golden.json` proves identical solver configs). Designs are visual only; the dashed outline in the viewport is the solver envelope. Viewport pre-fire shows the design; particle colours come from the library.
- All silhouettes are VISUAL APPROXIMATIONS, not traced from drawings. Documented: Pzgr.39 band width 12.3 mm, Pzgr.39/43 wider band (~17.8 mm, secondary), BR-471 sharp nose without cap, APCR core/carrier (core size is the solver estimate). Everything else is approximate; APDS/HEAT-FS/M82/SE57/IT shapes rest on designation only.
